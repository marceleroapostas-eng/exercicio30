# Exercício 30 - Soma de N Números

## Descrição

Programa desenvolvido em Java que solicita ao usuário uma quantidade de números e, em seguida, realiza a leitura desses números e calcula a soma de todos eles utilizando a estrutura de repetição `while`.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O usuário informa a quantidade de números que serão digitados e, posteriormente, os números que serão somados.

## Saída

O programa apresenta a soma de todos os números informados.
